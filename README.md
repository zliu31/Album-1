# Album-1 🎧

An interactive web application for picking your favorite rapper and album.

## Features

- **Rapper Selection**: Choose from Travis Scott, Drake, Kanye West, or Kendrick Lamar
- **Album Browser**: View and select from each artist's iconic albums
- **Smooth Animations**: Modern, responsive UI with gradient backgrounds and hover effects
- **Mobile Responsive**: Works seamlessly on all device sizes
- **Image Fallback**: Gracefully handles missing images by displaying text labels

## How to Use

1. Open `index.html` in your web browser
2. Select your favorite rapper from the main page
3. Browse their albums and pick your favorite
4. See your selection confirmed with album artwork

## Setup

Simply clone this repository and open `index.html` in any modern web browser. No additional dependencies or build steps required!

### Adding Images

To display album artwork and rapper images, add the appropriate image files to the `images/` directory. See `images/README.md` for a complete list of required images.

## Technology

- Pure HTML, CSS, and JavaScript
- No external dependencies
- Modern CSS with gradients, animations, and flexbox/grid layouts
- Responsive design with mobile-first approach
