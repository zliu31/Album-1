# Images Directory

This directory should contain the following image files for the rapper album picker application:

## Rapper Images
- `travis.webp` - Travis Scott profile image
- `drake.jpg` - Drake profile image
- `Kanye.png` - Kanye West profile image
- `kendrick.jpeg` - Kendrick Lamar profile image

## Album Cover Images

### Travis Scott Albums
- `Travis_Scott_-_Astroworld.png` - Astroworld album cover
- `rodeo.webp` - Rodeo album cover
- `utopia.jpg` - Utopia album cover

### Drake Albums
- `takecare.jpeg` - Take Care album cover
- `Scorpion_by_Drake.jpg` - Scorpion album cover
- `views.jpeg` - Views album cover

### Kanye West Albums
- `Graduation.jpeg` - Graduation album cover
- `Donda.jpg` - Donda album cover
- `college-dropout.webp` - The College Dropout album cover

### Kendrick Lamar Albums
- `Damn.jpeg` - DAMN. album cover
- `Butterfly.jpg` - To Pimp a Butterfly album cover
- `Mr.Morale.jpeg` - Mr. Morale & The Big Steppers album cover

## Note
The application includes fallback functionality - if an image fails to load, it will display the text name instead. This ensures the application remains functional even without all images present.
